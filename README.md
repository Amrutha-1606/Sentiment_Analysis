# Sentiment Analysis

## Description

Sentiment Analysis is a Natural Language Processing application that identifies whether a given sentence expresses a positive, negative, or neutral sentiment.

## Technology Used

- Python
- TextBlob
- Natural Language Processing

## Requirements

Python 3.x

## Installation

Install TextBlob using:

pip install textblob

## How to Run

1. Open the project folder in VS Code.
2. Open the VS Code terminal.
3. Install TextBlob.
4. Run the following command:

python app.py

5. Enter a sentence.
6. The program displays the sentiment.

## Example

Input:

I love this product

Output:

Sentiment: Positive

## Conclusion

This project demonstrates a simple application of Natural Language Processing for sentiment analysis.
